# Custom Patch Lab — campaign (Remotion)

One Remotion project for the six-ad campaign. Shared brand system in `src/shared/`
(tokens, fonts, kinetic type, badges, logo, transitions, grade); one folder per ad
with its `edl.json` (shot list + cut points) and composition.

| Ad | Composition | Length | Creative |
|---|---|---|---|
| 01 | `CustomPatchLabAd01` | 19.0 s | Cinematic + kinetic, no VO (temp score) |
| 02 | `CustomPatchLabAd02` | 20.0 s | Narrated artwork-to-product (ElevenLabs VO) |

All masters: 1080×1920 (9:16), 30 fps, H.264 + AAC, −14 LUFS.

```bash
npm install
./scripts/prepare-assets.sh [ad01|ad02]   # conform shots, logo mask, grain, audio mix
npm run studio
npm run render:preview  / render:final            # Ad 01
npm run render:ad02:preview / render:ad02:final   # Ad 02
npm run contact-sheet -- out/<file>.mp4
```

## Claims
`src/shared/brand.ts → CLAIMS`. Ad 02 *speaks* "zero setup fees", so its badge shows "$0 SETUP FEES" — **needs client sign-off before publishing**. The website tag (custompatchlab.com) is off until `websiteConfirmed` is true. **"$0 setup fees"** and **"USA based business"** appear only in the Gemini
styleframes, not in the approved Brand Identity System, so they are off. Set `setupFeeApproved: true`
once the client confirms it in writing and the 15–16 s beat switches to "$0 SETUP FEES."

## Audio — TEMP
`scripts/sound-design-ad01.py` / `-ad02.py` (toolkit: `scripts/sfxlib.py`) synthesize an original score and SFX (impact, whooshes, fabric foley,
risers, logo shimmer), normalized to −14 LUFS. It is entirely original, so nothing needs a licence,
but it is a **temp bed**. Replace the music with a commercially licensed instrumental hip-hop/trap
track (120 BPM, or re-time `src/edl.json`) before launch. The audio generated by Google Flow on the
clips is not used.

## Fonts
Fraunces (Ad 01 serif), Oswald (Ad 02 condensed grotesk), Montserrat (brand sans) — all SIL OFL, in `public/fonts/`.

## Ad 02 — voiceover-driven

- VO: `assets/source/ad02/audio/voiceover-elevenlabs.mp3` (16.20 s), script in `voiceover-script.txt`.
- `scripts/vo-timing.py` measures the 8 spoken phrases from the recording (silence gate) and places
  words inside them by syllable weight, snapped to energy dips → `src/ad02/vo-timing.json`. Every text cue
  in `Ad02.tsx` is looked up from that file. After a new take: re-run it, then `./scripts/build-audio.sh ad02`.
- VO starts at 0.4 s (after the opening impact) and ends at 16.45 s; the end card holds to 20.0 s.
- Cuts (`edl.json → cuts`) sit on a 100 BPM grid inside the VO's pauses: 3.6 / 5.4 / 6.6 / 8.4 / 12.0 / 13.8 s.
- Mix (`scripts/sound-design-ad02.py`): VO on top, music bed ducked ~14 dB and SFX ~9 dB under it
  (measured VO-over-bed while speaking: median 14.6 dB). Stems written to `public/audio/ad02-stem-{vo,bed}.wav`.
