```bash
npm install

npm run contact-sheet -- out/ad01-master-1080x1920.mp4
```

## Claims
`src/brand.ts → CLAIMS`. **"$0 setup fees"** and **"USA based business"** appear only in the Gemini
styleframes, not in the approved Brand Identity System, so they are off. Set `setupFeeApproved: true`
once the client confirms it in writing and the 15–16 s beat switches to "$0 SETUP FEES."

## Audio — TEMP
`scripts/sound-design.py` synthesizes an original score and SFX (impact, whooshes, fabric foley,
risers, logo shimmer), normalized to −14 LUFS. It is entirely original, so nothing needs a licence,
but it is a **temp bed**. Replace the music with a commercially licensed instrumental hip-hop/trap
track (120 BPM, or re-time `src/edl.json`) before launch. The audio generated by Google Flow on the
clips is not used.

## Fonts
Fraunces (display serif matching the styleframes) and Montserrat (brand sans), both SIL OFL, in `public/fonts/`.
