# Motion as Code: Madvert Labs Production Guide

How the Madvert Labs 60-second kinetic ad was made, and how to make the next one. You can
follow it yourself or hand it to Claude: start a session in this repo and say
*"Read motion/GUIDE.md, then make a new video from this brief…"*.

---

## 1. The idea in one paragraph

There is no timeline editor and there are no keyframes. Each scene (a **plate**) is a
TypeScript function `draw(ctx, t)` that paints the whole frame for time `t`. The **voiceover
is the clock**. We align the script to the audio word by word (`data/words.json`), and
every animation starts on a spoken word, looked up by content: `ws("we build it")`. Change
the voiceover, re-align, and the whole film re-times itself. Because a frame depends only
on `t`, the live preview and the final MP4 are identical. You can also render any single
frame as a still.

```
voiceover.mp3 ──► align.py ──► data/words.json ──┬──► scenes/*.ts + timeline.ts ──► render.ts ──► madvert-silent.mp4 ─┐
                                                 └──► sound.py (music + SFX cues + sonic logo) ──► mix.wav ───────────┴─► ffmpeg mux ──► final.mp4
```

## 2. Setup (new machine or new cloud session)

Requirements: **bun**, **ffmpeg** (with libx264) and **uv** (Python). No GPU or browser is
needed to render.

```sh
git clone <repo> && cd madvert-labs/motion
bun install
scripts/extract-frames.sh        # expands assets/video/*.mp4 into JPEG frame folders (git-ignored)
bun run sound                    # builds out/mix.wav (also copied to audio/preview-mix.wav)
bun run preview                  # http://localhost:5173/preview/
```

Preview keys: `space` play/pause · `←/→` 1 s (`shift` 5 s) · `,` `.` one frame ·
`[` `]` previous/next plate · `s` toggle subtitles · `?t=35` in the URL starts at 35 s.

## 4. The production process we followed (repeat this for every video)

1. **Brief.** Script, audience, style, scene list, what each line must *show*. The rule:
   *every important sentence creates a visual event; show the service working, not an icon.*
2. **Assets.** Logo files into `assets/brand/`, artworks into `assets/images/`, clips into
   `assets/video/`. Register new keys in `src/core/assets.ts` (`IMAGES` / `VIDEOS`).
   Missing visuals are drawn in code or generated (e.g. `make-boring-ad.ts`).
3. **Voiceover.** Put the MP3 in `audio/voiceover.mp3`.
4. **Align.** Edit `SCRIPT` (exact spoken text) and `SPOKEN` (how acronyms, URLs and
   numbers are said) in `scripts/align.py`, then `bun run align`. Check that the printed
   word count looks right.
5. **Plan the timeline.** Read `data/words.json` and put a cut in the breath before each
   line: `cut("we build brands", 0, 0.25)` = 0.25 s before "we".
6. **Build plates.** One file per scene in `src/scenes/`, registered in `src/timeline.ts`.
7. **Review with stills** (fast loop, about 1 s for a batch):
   ```sh
   bun scripts/render.ts stills --t 4.2,9.5,13.3 --out out/wip
   ls out/wip/*.png | xargs scripts/sheet.sh out/sheet.png     # 2-column contact sheet
   ```
   Check for empty or dead frames, text collisions, clipped words, overlaps with the subtitle
   zone (bottom ~150 px) and glyphs missing from a font.
8. **Subtitles.** Update `CHUNKS` in `src/components/subtitles.ts` (see §7).
9. **Sound.** Update the cue sheet in `scripts/sound.py` (`sfx()`) and the music sections
   (`music()`), then `bun run sound`.
10. **Draft render** (no motion blur, fast): `bun run render:draft`
11. **Final render** (3-sample motion blur, CRF 17, about 15–20 min at 1080p on 4 cores):
    ```sh
    bun run render                     # -> out/madvert-silent.mp4
    bun run sound
    ffmpeg -i out/madvert-silent.mp4 -i out/mix.wav -map 0:v -map 1:a \
      -c:v copy -c:a aac -b:a 320k -shortest -movflags +faststart out/final.mp4
    ```
12. **QC.** Pull frames from the final file (`ffmpeg -ss 12.3 -i out/final.mp4 -frames:v 1 x.png`)
    and run the checklist in §10.

Don't edit `src/` while a render is running. Workers load the code once at start.

## 5. Making a NEW video (step by step)

**Option A, new video for the same brand:** copy the folder so this ad stays reproducible.
```sh
cp -r motion motion-<name>      # e.g. motion-seo-ad
```
(Add `motion-<name>` to the root `tsconfig.json` `exclude` and to `eslint.config.mjs` ignores.)

**Option B, another brand:** same copy, then replace `assets/brand/*`, edit `C` and `F` in
`src/core/brand.ts`, and swap the font files.

Then:

1. Replace `audio/voiceover.mp3`; edit `SCRIPT` and `SPOKEN` in `scripts/align.py`; `bun run align`.
2. Set `DURATION` in `src/core/brand.ts` (VO length + `VO_OFFSET` + ~2 s end hold).
3. Delete or rename old plates; write new ones (template in §6); list them in `src/timeline.ts`.
4. Rewrite `CHUNKS` in `src/components/subtitles.ts` for the new script.
5. Rewrite `sfx()` cues in `scripts/sound.py` (they use the same phrase lookups).
   Update the section anchors in `music()`: `t_solution`, `t_reframe`, `t_end`, `t_pos`, `t_cta`.
6. Stills → draft → final, as in §4.

## 6. Writing a plate (template)

```ts
// src/scenes/15-example.ts
import { C, F, W, H } from "../core/brand";
import { background, card, text, chip, icon } from "../core/draw";
import { ep, prog, outExpo, outBack, inOutCubic, clamp, lerp } from "../core/ease";
import { ws, we } from "../core/words";
import { kline, shake } from "../components/kinetic";
import { ribbon } from "../components/ribbon";
import { browser, button } from "../components/ui";

export function drawExample(ctx: any, t: number) {
  const t0 = ws("we build it") - 0.25;          // scene-local anchor, always from the VO
  const [sx, sy] = shake(t, ws("it"), 10);      // impact shake on a word
  ctx.save(); ctx.translate(sx, sy);
  background(ctx, t, { grid: 0.5 });

  // a card that eases in, 0.6 s, starting at t0
  const a = ep(t, t0, 0.6, outBack);
  if (a > 0) card(ctx, 1000, 200, 700, 500, { alpha: clamp(a * 2) });

  // kinetic headline: each word animates on its own spoken word
  kline(ctx, t, {
    x: 140, y: 400, size: 120,
    words: [
      { s: "WE", t: ws("we build it"), anim: "rise" },
      { s: "BUILD", t: ws("build it"), anim: "rise" },
      { s: "IT.", t: ws("it"), anim: "slam", grad: true },
    ],
  });

  // growth ribbon drawing on along a path
  ribbon(ctx, [[100, 800], [900, 760], [1800, 800]], { to: ep(t, t0, 0.8, inOutCubic), width: 6, flow: t });
  ctx.restore();
}
```
Register it in `src/timeline.ts`:
```ts
{ id: "example", start: cut("we build it", 0, 0.25), in: { type: "swipe", dur: 0.45 }, draw: drawExample },
```

**Rules that keep it working:**
- Everything must be a function of `t`: no `Math.random()`, no state between frames. Use `hash(i)` / `noise(x)`.
- Time comes from words (`ws/we/cut`), never hard-coded seconds.
- A plate is also drawn slightly before its start and after its end during transitions, so make it look fine there.
- Keep the bottom ~150 px clear for subtitles (y > 900).
- Keep each `save()`/`restore()` pair balanced.

## 7. API cheat sheet

### Word timing: `src/core/words.ts`
| Call | Returns |
|---|---|
| `ws("phrase", n?)` | start time (s) of the n-th occurrence (0-based) |
| `we("phrase", n?)` | end time of the phrase |
| `cut("phrase", n?, lead?)` | start minus `lead` (default 0.12 s): use for scene cuts |
| `phrase("…")` | `{ s, e, i, j }` |

Matching ignores case and punctuation **but keeps apostrophes**: `"madvertlabs.com."`
matches as `madvertlabscom`, and `"don't"` as `don't`. A repeated word needs its occurrence
index: in this ad `"stop"` is `ws("stop", 0)` (opening) and `ws("stop", 1)` ("stop for").
Using a longer phrase is safer than an index: `ws("stop for")`.

### Easing: `src/core/ease.ts`
`ep(t, start, dur, easing)` gives eased 0→1 progress. Use it for almost everything.
`prog(t, a, b)` is linear 0→1. Curves: `outExpo` (snappy UI), `outQuart`, `outCubic`,
`inOutCubic`, `inOutExpo` (camera and transitions), `outBack(t, s)` (gentle overshoot),
`spring(t, k, d)` (settle), `inCubic`/`inExpo` (exits). Helpers: `lerp`, `clamp`,
`mixColor`, `rgba(hex, a)`, `hash(n)`, `noise(x)`.

### Kinetic type: `kline(ctx, t, line)`
```ts
{ x, y, size, align?: "left"|"center"|"right", weight?, family?, color?, ls?, gap?,
  out?, outAnim?, outDur?,                       // whole-line exit
  words: [{ s, t, anim?, dur?, color?, grad?, weight?, scale?, grey?, out?, outAnim?, outDur? }] }
```
- **In:** `rise` (mask reveal, the default), `slam` (scale punch), `blur`, `slideL`, `slideR`, `drop`, `type` (typewriter), `late` (delayed overshoot), `none`
- **Out:** `up`, `down` (masked), `fade`, `slideR`, `slideL`, `fall` (drops and rotates), `split` (words pull apart), `shrink`
- `grad: true` = brand gradient; `grey: time` = the word cools to grey (e.g. "COLD")
- Returns word boxes `{x, y, w, h}` for underlines and strikes. `shake(t, t0, amp)` gives a camera-shake offset; `underline(...)` draws an animated gradient underline.
- **Phrase replacement** (MARKETING → GROWTH SYSTEM): line A with `out` + `outAnim: "up"`, line B at the same x/y entering just after.

### Growth Ribbon: `ribbon(ctx, points | sample(points), opts)`
`from`/`to` (draw-on 0..1) · `width` · `flow` (pass `t`) · `speed` / `pulses` (travelling
lights) · `gaps: [[a, b]]` (broken system) · `grey` (0..1 desaturated) · `strands` · `glow` · `alpha`.
`pointAt(sample(pts), u)` gives `{x, y, a}` to move a dot (a lead or a coin) along the path.

### Drawing: `src/core/draw.ts`
`background(ctx, t, {grid, glowA, gx})` · `card(ctx, x, y, w, h, {r, fill, shadow, stroke, alpha})` ·
`text(ctx, s, x, y, {size, weight, family, color, align, ls})` · `eyebrow()` · `chip()` ·
`glow()` · `orb()` (cyan orb motif) · `cover(ctx, img, x, y, w, h, fx, fy, zoom, crop)` ·
`icon(ctx, name, x, y, size, color)` with names `check user chat calendar search bolt chart globe spark target phone mail gear layers play dollar link pen store` ·
`cursor(ctx, x, y, click)` · `lineChart(ctx, x, y, w, h, values0to1, progress)` · `streak()`.

### UI mockups: `src/components/ui.ts`
`browser(ctx, x, y, w, h, url)`, `phone(...)` and `laptop(ctx, x, y, w)` return the content
rect to draw inside. Also `toggle(ctx, x, y, on)`, `button(ctx, x, y, w, h, label, {press, dark})`,
`field(ctx, x, y, w, label, value, typedProgress, active)`, `avatar()`, `lines()` (skeleton
text), `okPill()`.

### Images and video
Add to `IMAGES` in `src/core/assets.ts`, then `img("key")`. For video, add to `VIDEOS` and
`scripts/extract-frames.sh`, then `video("key", localTime)`. Use `cover(..., crop)` to cut
off letterbox bars (find them with `ffmpeg -i x.mp4 -vf cropdetect -f null -`).

### Transitions: `in:` on a scene in `timeline.ts`
`swipe` (slanted wipe + light streak), `wipeUp`, `zoom` (push through), `flash` (white
flash), `fade`, `cut`. To add one, add a `case` in `transition()` in `src/compose.ts`.

### Subtitles: `src/components/subtitles.ts`
`CHUNKS = [[caption text, highlighted phrase], …]`. The chunks are consumed **in order and
by word count**, so together they must reproduce the script exactly, word for word.
A plate can set `subs: "dark" | "light" | "hide"` in the timeline. Render without
subtitles with `--subs 0`.

## 8. Sound: `scripts/sound.py`

- **Palette** (all synthesized): `click() tick() blip() pop() whoosh(d, up) impact(d, f0, f1) riser(d) chime(notes) typing(d) sub(d) sonic_logo()`.
- **Cue sheet** in `sfx()`: `C(sound, time, gain, pan)`, with times from the same `ws()/we()/cut()` lookups as the picture.
- **Music** in `music()`: tempo `BPM`, chord lists (`tension`, `lift`), section anchors, pad, bass, kick, hats and arp.
- **Mix:** the music ducks up to 9 dB and the SFX up to 4 dB under the voice, then a two-pass loudnorm to −14 LUFS / −1 dBTP.
- **Outputs:** `out/mix.wav` (full mix), `music.wav`, `sfx.wav`, and `music_sfx.wav` (no voice).
- **Licensed music:** read it in `__main__` instead of `music()` and keep the ducking.

## 9. Adding features (recipes)

| Feature | How |
|---|---|
| **Version without subtitles** | `bun scripts/render.ts video --subs 0 --out out/clean.mp4` |
| **4K master** | `--scale 2` (about 4× render time) |
| **15 s / 30 s cutdowns** | Record a short VO, align it, and build a timeline that reuses existing plate functions with new cut phrases. Or cut the master with `--from/--to` |
| **Vertical 9:16 (Reels/TikTok)** | Set `W=1080, H=1920` in `brand.ts` and re-lay-out each plate. Positions are absolute 1920×1080 coordinates, so this is a re-layout, not a flag |
| **New kinetic animation** | Add a case in `drawWord()` in `kinetic.ts` (in-anim switch or out-anim switch) |
| **New transition** | Add a `case` to `transition()` in `compose.ts` and the type in `core/scene.ts` |
| **New icon** | Add a `case` in `icon()` in `draw.ts` (24×24 path) |
| **New mockup** (tablet, watch, TV) | A function in `ui.ts` that draws the frame and returns the content `Rect` |
| **Real 3D** | Render a three.js scene to an offscreen canvas in the browser preview, or pre-render a frame sequence and load it like a video |
| **Client logos / results** | Add the real files to `assets/images/` and draw with `cover()`. Never invent them |
| **Faster renders** | `--workers` = CPU cores; `--samples 1` for drafts; render a range with `--from/--to` |

## 10. QC checklist (before the final render)

- Does every spoken capability get **shown working**, not just named?
- Is any frame empty or static for more than ~1–1.5 s? (Check stills at the start of each plate and between cues.)
- Text collisions, clipped words or overlaps with the subtitle zone?
- Official logo untouched and used correctly?
- Missing glyphs? (Sora has no `→`, so use Inter for arrows.)
- Any fabricated client names or results? Do any people appear who shouldn't? (Men only, per brief.)
- Sound: hits land on the words, the voice is always on top, and the mix measures −14 LUFS?
- Does the final frame say who, what, why different, and what to do next?

## 11. Gotchas we hit (and fixes)

- **Phrase not found:** the error names the phrase. Usually an occurrence index or punctuation (`madvertlabs.com` → use `ws("madvertlabs.com")`, not `"madvertlabs"`).
- **Alignment dictionary:** `add_word` fails if the word already exists in PocketSphinx's dictionary. Spell acronyms as letters in `SPOKEN` (`"seo": "s e o"`, `"ai": "a i"`) and only add true out-of-vocabulary words (`madvert`).
- **Masked words disappearing on exit:** moving exits (`split`, `slideR`, `fall`) turn the mask off automatically. If you add a new one, add it to that list in `kinetic.ts`.
- **Things visible before their cue** (e.g. connector lines drawn before their cards): gate every element on its own `ep(...) > 0`.
- **Dead frames at plate starts:** show skeleton or "inactive" states early and activate them on the cue (see `07-demand.ts`).
- **Don't edit code during a render.** Workers already loaded the old code, so the halves won't match.
